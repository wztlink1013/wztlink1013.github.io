12:T19cb,<p>Vue 3 采用了 <code>Proxy</code> 来实现响应式系统，主要是为了克服 Vue 2 使用的 <code>Object.defineProperty</code> 的局限性，并提高响应式数据的灵活性和性能。</p>
<h3 id="原因包括以下几点">原因包括以下几点：</h3>
<ol>
<li><strong>监听数组与对象的动态属性</strong>：</li>
</ol>
<ul>
<li>在 Vue 2 中，<code>Object.defineProperty</code> 只能监听对象已有的属性，无法直接检测新增加的属性，或者删除属性。对于数组，也只能监控特定的变更操作。</li>
<li><code>Proxy</code> 则可以直接监听对象属性的增加、删除操作，并且能够监控数组索引变化。</li>
</ul>
<ol start="2">
<li><strong>对整个对象的深度拦截</strong>：</li>
</ol>
<ul>
<li><code>Proxy</code> 可以对整个对象进行深度拦截，包括读取属性、设置属性、删除属性等操作，而不需要遍历对象的每个属性。</li>
<li>这使得 Vue 3 在处理复杂的数据结构时，性能更好，代码也更加简洁。</li>
</ul>
<ol start="3">
<li><strong>更好的性能</strong>：</li>
</ol>
<ul>
<li><code>Proxy</code> 在某些场景下比 <code>Object.defineProperty</code> 更高效。例如，Vue 2 需要对每个属性进行单独的处理，而 Vue 3 使用 <code>Proxy</code> 后，只需要为整个对象设置拦截器，减少了对数据结构的操作和维护成本。</li>
</ul>
<ol start="4">
<li><strong>支持更多操作</strong>：</li>
</ol>
<ul>
<li><code>Proxy</code> 支持更丰富的操作拦截，比如 <code>in</code> 操作符、属性枚举、<code>has</code> 操作符、<code>Reflect</code> API 等，这些都是 <code>Object.defineProperty</code> 无法做到的。</li>
</ul>
<ol start="5">
<li><strong>简化代码维护</strong>：</li>
</ol>
<ul>
<li>由于 <code>Proxy</code> 可以直接拦截对象的所有操作，Vue 3 的响应式系统实现逻辑相对 Vue 2 更为简单和一致，减少了在 Vue 2 中为了处理特殊情况所做的额外逻辑。</li>
</ul>
<p>总结来说，Vue 3 选择 <code>Proxy</code> 主要是为了弥补 <code>Object.defineProperty</code> 的局限性，提供更强大的功能、更好的性能和更简化的实现，提升框架的响应式体验。</p>
<p>Vue 3 使用 <code>Proxy</code> 主要是为了实现响应式系统的更强大和灵活性，替代了 Vue 2 中的 <code>Object.defineProperty</code>。<code>Proxy</code> 提供了更多的能力和更好的性能优化，以下是 Vue 3 使用 <code>Proxy</code> 的主要原因：</p>
<ol>
<li><strong>对所有属性的完整支持</strong>：</li>
</ol>
<ul>
<li>Vue 2 使用 <code>Object.defineProperty</code> 实现响应式，但它只能监听对象现有属性的读取和修改。如果给对象动态添加新属性或者删除属性，Vue 2 无法跟踪到这些变化，用户需要通过 <code>Vue.set</code> 或 <code>Vue.delete</code> 来手动处理。而 <code>Proxy</code> 可以拦截几乎所有操作（如新增、删除、读取、写入等），使响应式系统可以监听对象属性的增删改查，无需特殊方法。</li>
</ul>
<ol start="2">
<li><strong>支持数组、Map、Set 等更复杂的数据类型</strong>：</li>
</ol>
<ul>
<li><code>Object.defineProperty</code> 只能对普通对象和数组进行响应式处理，而 <code>Proxy</code> 可以直接处理 <code>Map</code>、<code>Set</code>、<code>WeakMap</code> 和 <code>WeakSet</code> 等数据结构，使这些更复杂的数据结构也能够响应式化，提升了框架的灵活性。</li>
</ul>
<ol start="3">
<li><strong>性能提升</strong>：</li>
</ol>
<ul>
<li>Vue 2 的响应式系统需要递归遍历对象的所有属性来进行深度监听，性能消耗较大。Vue 3 使用 <code>Proxy</code> 可以按需代理属性，减少不必要的性能开销，因为 <code>Proxy</code> 可以在属性访问时动态拦截操作，只有在访问属性时才会进行监听。</li>
</ul>
<ol start="4">
<li><strong>更好的语言支持</strong>：</li>
</ol>
<ul>
<li><code>Proxy</code> 允许拦截很多不同类型的操作，如属性的 <code>get</code>、<code>set</code>、<code>has</code>、<code>deleteProperty</code> 等。这意味着 Vue 3 可以更精确地处理响应式需求，避免很多边界情况，同时提供了更清晰、可扩展的架构。</li>
</ul>
