视频的无伤切割

尼采般地抒情·2021-05-16·1 分钟

前言：对于一个很大的视频，不方便和其他用户使用软件传输，需要将其切割成数个小容量视频，两种方法，一种是利用其他软件来进行切割，比如pr；另一种是利用万能的ffmpeg，这个需求采用后者方法。

需求视频为8G多，总时长01：51：00，QQ在线传输一次最多4G，所以需要将目标视频切成三段，需要的命令如下：

ffmpeg -ss 00:00:00 -i target.mp4 -c copy -t 00:45:00 target-part1.mp4 #Start～00:45:00
ffmpeg -ss 00:45:00 -i target.mp4 -c copy -t 00:45:00 target-part2.mp4 #00:45:00~01:30:00
ffmpeg -ss 01:30:00 -i target.mp4 -c copy -t 00:21:00 target-part3.mp4 #01:30:00～End
