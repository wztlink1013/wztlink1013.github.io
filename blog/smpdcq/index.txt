12:Tf77,<p>前言：for循环里面的i++和++i在平时使用感觉是几乎一样的，但是之前写代码，特别是数据结构课程学链表那会，经常需要做的就是一个节点的next指向什么才结束这样一种情况，当时总是不自觉地将i++调整为++i就能运行成功，这个点比较模糊，查资料才发现存在<strong>只有++i可以返回左值</strong>这一情况。</p>
<hr>
<p>先来一段常规使用：</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/smpdcq/1627270650151-857f8953-7e79-4055-a838-2b26b96aaf0a.png" alt="" loading="lazy" decoding="async"></p>
<p>这个没有相关的差别</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/smpdcq/1627271346217-4ae80a1d-979b-42cd-b6ff-8fdc271926ab.png" alt="" loading="lazy" decoding="async"></p>
<p>一个返回+之前的值一个返回+之后的值，也是字面理解。</p>
<blockquote>
<p>左值：在内存存储空间里面有确定的存储地址的值。</p>
<p>判断是否为左值：看是否允许取地址&#x26;运算符获得对应的内存地址。</p>
</blockquote>
<p><strong>++i可以返回左值，i++不可以。</strong>（下面的截图对i++报错，对++i没有报错）</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/smpdcq/1627437597153-a59bb261-e406-46f3-8bbb-34af9278b55d.png" alt="" loading="lazy" decoding="async"></p>
<p>i++和++i的实现：</p>
<div class="code-block"><pre><code class="hljs language-cpp"><span class="hljs-comment">// 前缀形式：++i</span>
<span class="hljs-type">int</span>&#x26; <span class="hljs-type">int</span>::<span class="hljs-keyword">operator</span>++() <span class="hljs-comment">//这里返回的是一个引用形式，就是说函数返回值也可以作为一个左值使用</span>
{<span class="hljs-comment">//函数本身无参，意味着是在自身空间内增加1的</span>
  *<span class="hljs-keyword">this</span> += <span class="hljs-number">1</span>;  <span class="hljs-comment">// 增加</span>
  <span class="hljs-keyword">return</span> *<span class="hljs-keyword">this</span>;  <span class="hljs-comment">// 取回值</span>
}

<span class="hljs-comment">//后缀形式：i++</span>
<span class="hljs-type">const</span> <span class="hljs-type">int</span> <span class="hljs-type">int</span>::<span class="hljs-keyword">operator</span>++(<span class="hljs-type">int</span>) <span class="hljs-comment">//函数返回值是一个非左值型的，与前缀形式的差别所在。</span>
{<span class="hljs-comment">//函数带参，说明有另外的空间开辟</span>
  <span class="hljs-type">int</span> oldValue = *<span class="hljs-keyword">this</span>;  <span class="hljs-comment">// 取回值</span>
  ++(*<span class="hljs-keyword">this</span>);  <span class="hljs-comment">// 增加</span>
  <span class="hljs-keyword">return</span> oldValue;  <span class="hljs-comment">// 返回被取回的值</span>
}
</code></pre><button type="button" class="code-copy" data-copy-code="" aria-label="复制代码"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" aria-hidden="true"><rect x="8" y="8" width="12" height="12" rx="2"></rect><path d="M16 8V4a1 1 0 0 0-1-1H4a1 1 0 0 0-1 1v11a1 1 0 0 0 1 1h4"></path></svg><span>复制</span></button></div>
<p>从这个代码也可以看出++i的效率是优于i++的，尽管很微弱。</p>
<blockquote>
<p>[!CAUTION]</p>
<p>大多数编译器已经对这两种使用方式封装，使其普通使用的效果几乎一致。</p>
</blockquote>
<blockquote>
<p>[!TIP]</p>
<p>今后尽量使用++i，特别是C++写题的时候。</p>
</blockquote>
