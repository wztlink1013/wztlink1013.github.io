Cursor 使用 Antigravity-Manager 接入 Antigravity 模型

尼采般地抒情·2026-01-26·1 分钟

前言： 在使用 Cursor 接入自定义模型的过程中，直接连接本地服务往往会遇到各种限制和报错问题。Antigravity-Manager 提供了一种相对简洁的本地模型管理与服务方案，但在实际使用中，仍需要配合内网穿透工具才能顺利在 Cursor 中调用。

Antigravity-Manager下载

下载地址：https://github.com/lbjlaq/Antigravity-Manager/releases

添加Google账号

启动 Antigravity-Manager 后，按需添加 Google 账号，用于后续模型或服务的正常调用。

具体添加方式可参考项目文档中的账号配置说明

添加cloudflared内网穿透

为了让 Cursor 正常访问本地运行的 Antigravity-Manager 服务，需要配置 Cloudflared 内网穿透。

如果不添加上述cloudflare内网穿透，直接在Cusror添加http://127.0.0.1:8045/v1会报错
