<p><strong>前言：今年GitHub的各种操作被屏蔽的挺迷的，一开始我只是以为偶尔报个连接失败的port443的错误，但是后来经常性的出现本地push不上GitHub的情况，在此情况记录一下各种情况（clone、pull、push……）连接不上的解决办法。</strong></p>
<h2 id="一报错信息与原因分析">一、报错信息与原因分析</h2>
<h3 id="报错信息">报错信息</h3>
<div class="code-block"><pre><code class="hljs language-bash">Git push出(10054)/(port 443：<span class="hljs-keyword">time</span> out)错

git push error: RPC failed; curl 56 OpenSSL SSL_read: SSL_ERROR_SYSCALL, errno 10054
</code></pre><button type="button" class="code-copy" data-copy-code="" aria-label="复制代码"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" aria-hidden="true"><rect x="8" y="8" width="12" height="12" rx="2"></rect><path d="M16 8V4a1 1 0 0 0-1-1H4a1 1 0 0 0-1 1v11a1 1 0 0 0 1 1h4"></path></svg><span>复制</span></button></div>
<h3 id="原因分析">原因分析</h3>
<ol>
<li>由于Http协议错误，当 pull 或者 clone 的时候，或者是 github 某个CDN被qiang屏蔽所致。</li>
<li>用了kexueshangwang工具之后，由于更改代理服务器连接端口，导致本地push偶尔失败（但是以前有用）。</li>
</ol>
<h2 id="二常规解决方案">二、常规解决方案</h2>
<blockquote>
<p>[!TIP]</p>
<p>2021.06.29更新解决方法：【针对clone失败】https的连接不行，那就用ssh的连接。2021.07.13更新解决方案：【针对pull、push失败】ssh连接push连接不行，那就用token来push。</p>
</blockquote>
<blockquote>
<p>[!TIP]</p>
<p>常规解决方法：第一种方法是下面的三条命令，另外如果用了该三条命令还不行，那就ctrl + c ，再进行输入命令，以此往复，总会出现GitHub的登录框的……；第二种方法就是在本地对host进行更改，让其可以访问github网站的相关ip；</p>
</blockquote>

<h3 id="常规解决方案2改变本地hosts文件">常规解决方案2：改变本地hosts文件</h3>
<p>在<a href="https://www.ipaddress.com/" rel="noopener noreferrer">https://www.ipaddress.com/</a>里面查找下面三个域名的ip地址</p>
<ul>
<li>github.com</li>
<li>github.global.ssl.fastly.net</li>
<li>codeload.github.com</li>
</ul>
<p>将其添加到本电脑hosts文件当中</p>
<p><code>C:\Windows\System32\drivers\etc\hosts</code> </p>
