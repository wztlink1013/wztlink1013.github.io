<h2 id="hermes-agent和coding-agent">Hermes Agent和Coding Agent</h2>
<p>个人工作流层面，superpowers、AGENTS.md等<strong>Harness Engineering</strong>在<strong>Coding Agent</strong>（Cursor/Claude Code/ CodeX）里写代码。<strong>OpenClaw / Hermes</strong> 不写代码——只做调研归纳、竞品扫描、会议/碎片整理、文档、灵感。</p>
<p>之前两三个月主用 <strong>OpenClaw + Discord</strong>，多个agent 分工收集。</p>
<p><img src="https://assets.musecanto.com/uvxwY7KW9sGYbUfSojyke/sv-books/2026_05_22_editorimg_4f956185-812c-4039-a648-87691a66ce22.png" alt="image" loading="lazy" decoding="async"></p>
<p>痛点是：<strong>过程看不清</strong>、<strong>同类调研每次重讲背景</strong>。于是</p>
<p>最近打算切 <strong>Hermes Agent</strong>，并刻意换习惯验证：</p>
<ul>
<li><strong>Hermes + Telegram + MiMo</strong>（百亿 Token 活动额度 <a href="https://100t.xiaomimimo.com/" rel="noopener noreferrer">++https://100t.xiaomimimo.com/++</a>，扛长对话调研）</li>
<li><strong>OpenClaw + Discord</strong> 收成搜集哨，不再扩新 agent</li>
<li><strong>后续场外 core 专门深耕 Hermes</strong></li>
</ul>
<p>关键判断：<strong>OpenClaw</strong>和<strong>Hermes</strong>属于++「信息与认知劳动」++；写代码另有战场，<strong>Cursor</strong>、<strong>Claude Code</strong>、<strong>CodeX</strong>。别混成一个工具期望，++不要想着用Hermes写代码，个人不建议这么做，因为具体实操起来还是很不方便，并且很浪费token。++</p>
