<h3 id="sitemap">sitemap</h3>

<h3 id="robotstxt">robots.txt</h3>
<p>robots文件是一个文本文件，用于向搜索引擎指示哪些页面可以访问和索引，哪些页面应该被忽略。通过优化 robots文件，可以提高网站在搜索引擎中的排名和曝光度。</p>
<div class="code-block"><pre><code class="hljs language-plain"># https://www.wztlink1013.com
User-agent: *
Disallow: /
Sitemap: https://www.wztlink1013.com/sitemap.xml
</code></pre><button type="button" class="code-copy" data-copy-code="" aria-label="复制代码"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" aria-hidden="true"><rect x="8" y="8" width="12" height="12" rx="2"></rect><path d="M16 8V4a1 1 0 0 0-1-1H4a1 1 0 0 0-1 1v11a1 1 0 0 0 1 1h4"></path></svg><span>复制</span></button></div>
<ul>
<li>User-agent：* 表示允许所有搜索引擎访问您的网站，如果限定的话，则键入 <code>[搜索引擎名称]</code></li>
<li>Sitemap：说明sitemap文件url</li>
<li>Disallow：<code>/</code>表示禁止该搜索引擎访问您的网站中所有页面和文件</li>
</ul>
