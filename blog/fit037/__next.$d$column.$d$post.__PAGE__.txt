<h2 id="一思路流程">一、思路流程</h2>
<blockquote>
<p><strong>和做数学题一样</strong></p>
</blockquote>
<h3 id="目做算法">目做（算法）</h3>
<ul>
<li>设计解决问题的解决算法：把这道题/这个问题的解决思路想清楚！</li>
<li>算法的本质：寻找规律并实现</li>
<li>如何寻找规律：发现输入和输出的关系，寻找突破点</li>
</ul>
<h3 id="手做数据结构">手做（数据结构）</h3>
<p><strong>实现 = 编码 + 调试</strong></p>
<ul>
<li>动手实现，要想好<strong>用那些数据结构</strong>来实现上面的“目做”的思路</li>
<li>可以将一个问题分解成小的功能（划分函数），一个一个功能解决之！</li>
<li>不要思路不明确就进行写代码实现，不然到后面的调试会很复杂，就出现了那种“修水管”那张滑稽图一样</li>
</ul>
<h3 id="脑做体系">脑做（体系）</h3>
<ul>
<li>回顾知识点，充实知识体系</li>
<li>学过的数据结构要清楚理解他的常用操作，学完就要将其“封装”好，用的时候才能更好的用，还有写题过程中，要<strong>总结“错题”（和学数学一样）</strong>，这样下次才不会被同一个问题卡住，要学会总结</li>
</ul>
<h2 id="二解法总结">二、解法总结</h2>
<p>解法总结</p>
<p>SOP</p>
<p>暴力解法（内置API）</p>
<p>最直观的解法</p>
<p>暴力解法（穷举算法）</p>
<p>分类讨论</p>
<p>字符串类的</p>
<ul>
<li>内置API</li>
<li>正则表达式</li>
</ul>
<p>链表类</p>
<ul>
<li>双指针</li>
<li>头部加一个虚拟节点</li>
</ul>
<p>给定双指针，同向移动、相向移动、背向移动等处理</p>
<ul>
<li><a href="https://www.yuque.com/wztlink1013/blog/amgx01" rel="noopener noreferrer">11. 盛最多水的容器</a></li>
</ul>
<p>子问题叠加类</p>
<ul>
<li>分治算法（子问题不重叠）</li>
<li>动态规划算法（子问题重叠）</li>
<li>贪心算法</li>
<li>穷举算法</li>
</ul>
<p>递归算法</p>
<p>适用于递归解决的问题通常有两个特点：</p>
<ol>
<li>递归性：能将规模为n的问题简化为n-1的问题，并且规模为n的问题和规模为n-1的问题性质一样</li>
<li>可终结性：不能无限递归下去，小到一定程度能够得出结果</li>
</ol>
<blockquote>
<p>eg：前n个自然数的和、n个数之和这两个问题就可以用递归来解决</p>
</blockquote>
