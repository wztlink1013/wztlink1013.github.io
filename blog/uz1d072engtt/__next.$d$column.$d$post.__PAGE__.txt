<h2 id="一javascript编程语言">一、JavaScript编程语言</h2>
<h3 id="解释型语言和编译型语言">解释型语言和编译型语言</h3>
<p>计算机不能直接理解任何除机器语言以外的语言，所以必须要把程序员所写的程序语言翻译成机器语言才能执行程序。程序语言翻译成机器语言的工具，被称为翻译器。</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1611883945965-edfd63f6-b312-4daa-990e-aa7fb8d29640.png" alt="" loading="lazy" decoding="async"></p>
<ul>
<li>翻译器翻译的方式有两种：一个是编译，另外一个是解释。两种方式之间的区别在于翻译的时间点不同</li>
<li>编译器是在代码执行之前进行编译，生成中间代码文件</li>
<li>解释器是在运行时进行及时解释，并立即执行(当编译器以解释方式运行的时候，也称之为解释器)</li>
</ul>
<blockquote>
<p>执行过程</p>
</blockquote>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1611883933551-3185c915-4a31-4151-a6c6-9212e11d336c.png" alt="" loading="lazy" decoding="async"></p>
<h3 id="是什么">是什么</h3>
<ul>
<li>JavaScript 是世界上最流行的语言之一，是一种运行在客户端的脚本语言 （Script == 脚本）</li>
<li>脚本语言：不需要编译，运行过程中由 js 解释器( js 引擎）逐行来进行解释并执行</li>
<li>现在也可以基于 Node.js 技术进行服务器端编程</li>
</ul>
<h3 id="用途">用途</h3>
<ul>
<li>表单动态校验（密码强度检测） （ JS 产生最初的目的 ）</li>
<li>网页特效</li>
<li>服务端开发(Node.js)</li>
<li>桌面程序(Electron)</li>
<li>App(Cordova)</li>
<li>控制硬件-物联网(Ruff)</li>
<li>游戏开发(cocos2d-js)</li>
</ul>
<h3 id="浏览器执行js简介">浏览器执行JS简介</h3>
<p>浏览器分成两部分：</p>
<ol>
<li>渲染引擎：用来解析HTML和CSS，俗称内核。比如Chrome浏览器是blink，老版本是webkit。</li>
<li>JS引擎：也称JS解释器，用来读取网页中的JavaScript代码，对其处理后运行。比如Chrome的V8引擎。</li>
</ol>
<blockquote>
<p>浏览器本身并不会执行JS代码，而是通过内置 JavaScript 引擎(解释器) 来执行 JS 代码 。JS 引擎执行代码时逐行解释每一句源码（转换为机器语言），然后由计算机去执行，所以 JavaScript 语言归为脚本语言，会逐行解释执行。</p>
</blockquote>
<h3 id="javascript的组成">JavaScript的组成</h3>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1611883453712-2dfb6f14-cf77-4475-ad87-5826124bc43f.png" alt="" loading="lazy" decoding="async"></p>
<ol>
<li><strong>ECMAScript</strong></li>
</ol>
<p>ECMAScript 是由ECMA 国际（ 原欧洲计算机制造商协会）进行标准化的一门编程语言，这种语言在万维网上应用广泛，它往往被称为 JavaScript或 JScript，但实际上后两者是 ECMAScript 语言的实现和扩展。</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1611883470657-6e9bb00b-781e-46d3-99e7-64afd35e3758.png" alt="" loading="lazy" decoding="async"></p>
<p>ECMAScript：规定了JS的编程语法和基础核心知识，是所有浏览器厂商共同遵守的一套JS语法工业标准。</p>
<ul>
<li><a href="https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/JavaScript_technologies_overview" rel="noopener noreferrer">JavaScript 技术概览 - JavaScript | MDN</a></li>
</ul>
<ol start="2">
<li><strong>DOM——文档对象模型</strong></li>
</ol>
<p>文档对象模型（DocumentObject Model，简称DOM），是W3C组织推荐的处理可扩展标记语言的标准编程接口。通过 DOM 提供的接口可以对页面上的各种元素进行操作（大小、位置、颜色等）</p>
<ol start="3">
<li><strong>BOM——浏览器对象模型</strong></li>
</ol>
<p>浏览器对象模型(Browser Object Model，简称BOM) 是指浏览器对象模型，它提供了独立于内容的、可以与浏览器窗口进行互动的对象结构。通过BOM可以操作浏览器窗口，比如弹出框、控制浏览器跳转、获取分辨率等。</p>
<h2 id="二变量">二、变量</h2>
<p>“行为怪异的<code>var</code>所造成的各种问题。”</p>
<p><em>《JavaScript高级程序设计》</em></p>
<h3 id="var和let和const">var和let和const</h3>
<p><strong>【var】</strong></p>
<ul>
<li>在全局区域声明是全局变量</li>
<li>在<strong>函数里面</strong>用var声明变量的时候是局部变量，但是省略var的时候，就变成全局变量了（坑……），好在严格模式下如果在函数里面这样定义会报错</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1617867733497-db043164-d28e-48e8-8bd7-2a9b1d30203a.png" alt="" loading="lazy" decoding="async"></p>
<ul>
<li>会变量提升，把所有变量声明都拉到函数作用域的顶部，所以在同一个域里面，var定义的变量，先使用在定义也是可以的。</li>
<li>可以多次定义赋值</li>
</ul>
<div class="code-block"><pre><code class="hljs language-javascript"><span class="hljs-keyword">var</span> i = <span class="hljs-number">0</span>;
<span class="hljs-keyword">var</span> i = <span class="hljs-number">0</span>;

<blockquote>
<p>编写代码不建议使用var来定义变量了</p>
</blockquote>
<p><strong>【let】</strong></p>
<ul>
<li>作用范围：块作用域</li>
<li>会有冗余声明（不可以多次定义赋值）</li>
<li>不会变量提升，俗称“暂时性死区”</li>
</ul>
<p><strong>【const】</strong></p>
<ul>
<li>作用范围：块作用域</li>
<li><strong>声明变量必须同时初始化变量</strong></li>
<li>不允许重复声明</li>
<li>尝试修改变量的值报错，但对对象操作就不一样了</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/uz1d072engtt/1617866749694-8c13df91-894d-41ba-a6bf-4545875594be.png" alt="" loading="lazy" decoding="async"></p>
<blockquote>
<p>使用建议：参照《JavaScript高级程序设计》书中所说的，“不使用var，const优先，let次之”。</p>
</blockquote>
<h3 id="作用域链">作用域链</h3>
<p>因为var可以多次声明这一个特点，就产生出了一个问题，在函数里面声明一个变量，在函数外也声明一个同名的变量，就会导致接下来的代码使用哪一个变量的情况。分析是哪个其实也好办，就是看调用的这个函数离哪个声明的变量最近，哪个最近取哪个。</p>
<p><strong>作用域链有其解决的办法，那就是利用作用域链，但是使用let和const更为方便</strong>。</p>

<h3 id="预解析和代码执行">预解析和代码执行</h3>
<p>浏览器的js解析器当中，会将js代码分两步执行，分别为，预解析和执行代码</p>
<ul>
<li>预解析：在当前作用域下, JS 代码执行之前，浏览器会默认把带有 var 和 function 声明的变量在内存中进行提前声明或者定义，这个机制也叫<code>hoisting</code>（变量提升）</li>
<li>代码执行： 从上到下执行JS语句</li>
</ul>
<h2 id="三基本数据类型">三、基本数据类型</h2>
<h3 id="8种数据类型">8种数据类型</h3>
<p>最新的 ECMAScript 标准定义了 8 种数据类型：</p>
<p>七种基本<strong>数据类型</strong>：</p>
<ol>
<li>数字（<strong>Number</strong>），整数或浮点数，例如： 42 或者 3.14159。</li>
<li>字符串（<strong>String</strong>），字符串是一串表示文本值的字符序列，例如："Howdy" 。</li>
<li>布尔值（<strong>Boolean</strong>），有 2 个值分别是：true 和 false.</li>
<li><strong>undefined</strong>，和 null 一样是一个特殊的关键字，undefined 表示变量未赋值时的属性。</li>
<li><strong>null</strong>，一个表明 null 值的特殊关键字。JavaScript 是大小写敏感的，因此 null 与 Null、NULL或变体完全不同。</li>
<li>任意精度的整数 (<strong>BigInt</strong>) ，可以安全地存储和操作大整数，甚至可以超过数字的安全整数限制。</li>
<li>代表（<strong>Symbol</strong>）( 在 ECMAScript 6 中新添加的类型).。一种实例是唯一且不可改变的数据类型。</li>
<li>以及对象（<strong>Object</strong>）。</li>
</ol>
<h3 id="自动确定类型机制">自动确定类型机制</h3>
