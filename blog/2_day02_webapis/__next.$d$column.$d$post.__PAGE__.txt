4:T89e7,<h3 id="节点概述">节点概述</h3>
<p>网页中的所有内容都是节点（标签、属性、文本、注释等），在DOM 中，节点使用 node 来表示。HTML DOM 树中的所有节点均可通过 JavaScript 进行访问，所有 HTML 元素（节点）均可被修改，也可以创建或删除。</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1612518358489-a0521202-b32d-46a9-9b8d-f0cfe9afc455.png" alt="" loading="lazy" decoding="async"></p>
<p>一般地，节点至少拥有nodeType（节点类型）、nodeName（节点名称）和nodeValue（节点值）这三个基本属性。</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1612518358548-9283575f-7aef-450d-bc6e-b9d3a4384cc2.png" alt="" loading="lazy" decoding="async"></p>
<blockquote>
<p>节点层级：利用 DOM 树可以把节点划分为不同的层级关系，常见的是<strong>父子兄层级关系</strong>。</p>
</blockquote>
<h2 id="父节点">父节点</h2>
<h3 id="nodeparentnode">node.parentNode</h3>
<ul>
<li>返回某节点的父节点，最近的一个父节点</li>
<li>如果没有父节点，则返回null</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1616056309357-b2a256d0-2a4d-4983-80f9-1eed069c3890.png" alt="" loading="lazy" decoding="async"></p>
<h2 id="子节点">子节点</h2>
<h3 id="parentnodechildnodes">parentNode.childNodes</h3>
<ul>
<li>返回指定节点的子节点的集合，会即时更新</li>
<li>会返回所有的节点（包含元素节点、文本节点等）</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1616056553404-55b8fe19-9bea-413d-9cb1-6554380831af.png" alt="" loading="lazy" decoding="async"></p>
<h3 id="parentnodechildren">parentNode.children</h3>
<ul>
<li>只读属性</li>
<li>只返回元素节点</li>
<li>非标准，但是各个浏览器都支持</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1616056710609-4bb68282-b6ae-4240-b9be-a9faea530ab2.png" alt="" loading="lazy" decoding="async"></p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1616057002507-4244db60-7bf0-4e95-b68b-acb4d4d62d8d.png" alt="" loading="lazy" decoding="async"></p>
<h3 id="parentfirstchild">parent.firstChild</h3>
<p><img src="https://blogimage.musemvp.com/v1.0.0/2_day02_webapis/1616057242192-2bb01e66-de7d-4220-afc2-499adbdcc3de.png" alt="" loading="lazy" decoding="async"></p>
<ul>
<li>返回第一个子节点，找不到返回null，包含所有节点</li>
</ul>
<h3 id="parentlastchild">parent.lastChild</h3>
<ul>
<li>返回最后一个子节点，找不到返回null，包含所有节点</li>
</ul>
<h3 id="parentfirstelementchild">parent.firstElementChild</h3>
<ul>
<li>返回第一个子元素节点，找不到返回null</li>
<li>IE9以上支持</li>
</ul>
<h3 id="parentlastelementchild">parent.lastElementChild</h3>
<ul>
<li>返回最后一个子元素节点，找不到返回null</li>
<li>IE9以上支持</li>
</ul>
