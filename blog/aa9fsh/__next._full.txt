1d:T153c,<p><code>jQuery</code>只是对原生的<code>JavaScript</code>进行封装，说白了就是封装成伪数组，所以记住它的一些调用方法就可以了</p>
<h2 id="参考资料">参考资料</h2>
<ul>
<li><a href="https://jquery.cuishifeng.cn/" rel="noopener noreferrer">jQuery API 速查表 --作者：Shifone</a></li>
<li><a href="https://www.processon.com/view/link/5b7d6458e4b0534c9bb76ad9#map" rel="noopener noreferrer">jQuery思维导图</a></li>
</ul>
<h2 id="一些特性">一些特性</h2>
<ul>
<li>
<p><code>$</code>符号：jq里面的顶级对象</p>
</li>
<li>
<p>入口函数：在DOM里面的DOMContentLoaded，在$里面直接赋予入口函数即可</p>
</li>
<li>
<p>jq对象和DOM对象：</p>
</li>
</ul>
<p>两者之间的函数调用不能互换（因为是被封装成了伪数组）</p>
<p>jq转换为DOM：加数组下标即可（因为是被封装成了伪数组，利用索引即可）</p>
<p>DOM转换为jq：使用$符号即可（括号不加引号），或者是get(索引值)</p>
<h2 id="常用api">常用API</h2>
<h3 id="选择器操作">选择器操作</h3>
<ul>
<li>元素获取：之前的CSS选择器（基础选择器、复合选择器）怎么写，这里直接就放到$里面即可</li>
</ul>
<p>筛选选择器</p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/aa9fsh/1617359781992-e02802ae-f357-4987-a8a0-46cc0c5be69a.png" alt="" loading="lazy" decoding="async"></p>
<ul>
<li>
<p>隐式迭代：如果获取的元素是一个数组，那么对其赋予的新操作，会隐式遍历</p>
</li>
<li>
<p>元素属性操作：css("属性","值")函数</p>
</li>
<li>
<p>元素节点操作</p>
</li>
</ul>
<p><img src="https://blogimage.musemvp.com/v1.0.0/aa9fsh/1617359820567-38b9fad2-deb7-429f-9d21-8f9676563426.png" alt="" loading="lazy" decoding="async"></p>
<ul>
<li>
<p>事件：.mouseover()、.click()</p>
</li>
<li>
<p>.show()、.hide()：元素显示和隐藏</p>
</li>
<li>
<p>$(this)当前这个对象</p>
</li>
</ul>
<h3 id="样式操作">样式操作</h3>
<p>样式的操作还是和之前的DOM一样，有两种，一种是逐个设置该元素的属性和值，另一种就是改变其类，jq里面也是这个大题思路，不过有不同</p>
<ul>
<li>单一设置：.css()函数，一个参数的时候，返回该参数的值，两个参数的时候，即赋予该属性及值</li>
<li>clsss设置</li>
</ul>
<p>.addClass("类名")：如果该元素没有该类，则加上</p>
<p>.removeClass()：移除指定类名</p>
<p>.toggle()：如果该元素有该类则删除，如果没有该类则加上</p>
<ul>
<li>class设置和DOM里面className区别是前者不会删除原本的类，后者会</li>
</ul>
<h3 id="效果操作">效果操作</h3>
<p>jq封装了很多的效果，具体可以详查相关文档    </p>
<p><img src="https://blogimage.musemvp.com/v1.0.0/aa9fsh/1617361907950-d1d89194-401d-46aa-9471-34139e3e00df.png" alt="" loading="lazy" decoding="async"></p>
<h3 id="属性操作">属性操作</h3>
<ul>
<li>
<p>prop()：得到/设置元素固有的属性及值</p>
</li>
<li>
<p>attr()：得到/设置元素自定义的属性及值</p>
</li>
<li>
<p>data()：数据缓存</p>
</li>
</ul>
<h3 id="内容文本值操作">内容文本值操作</h3>
<ul>
<li>
<p>html()：相当于innerHTML</p>
</li>
<li>
<p>text()：相当于innerText</p>
</li>
<li>
<p>val()：操作表单的值（没有参数是获取值，有一个参数是设置）</p>
</li>
</ul>
<h3 id="元素操作">元素操作</h3>
<blockquote>
<p>[!NOTE]</p>
<p>遍历</p>
</blockquote>
<blockquote>
<p>第一种表达：</p>
</blockquote>
<ul>
<li>$("div").each(function(index,ele){XXXX})</li>
<li>其中index是索引号，ele得到的是DOM对象</li>
</ul>
<blockquote>
<p>第二种表达</p>
</blockquote>
<ul>
<li>$.each(Object,function(index,ele){XXXXX})</li>
<li>主要用于数据处理</li>
</ul>
<blockquote>
<p>[!NOTE]</p>
<p>创建</p>
</blockquote>
<p>直接在$里面双引号加上需要创建的标签</p>
<blockquote>
<p>[!NOTE]</p>
<p>添加</p>
</blockquote>
<blockquote>
<p>第一种关系：添加生成父子关系</p>
</blockquote>
<ul>
<li>append("")</li>
<li>prepend("")</li>
</ul>
<blockquote>
<p>第二种关系：添加生成兄弟关系</p>
</blockquote>
<ul>
<li>after("")</li>
<li>before("")</li>
</ul>
<blockquote>
<p>[!NOTE]</p>
<p>删除</p>
</blockquote>
<ul>
<li>
<p>remove()：移除选定节点</p>
</li>
<li>
<p>empty()：清空所选节点的左右子节点</p>
</li>
<li>
<p>html("")：将所选节点的html内容制空（相当于删除节点了）</p>
</li>
</ul>
