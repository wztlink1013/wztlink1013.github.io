<h2 id="一nodejs包管理">一、Nodejs包管理</h2>
<ul>
<li><a href="https://rushjs.io/zh-cn/" rel="noopener noreferrer">Rush</a>：提高性能，提出“中心”包管理</li>
<li><a href="https://docs.npmjs.com/getting-started/what-is-npm" rel="noopener noreferrer">NPM</a>: 它是当今最广泛的 JavaScript 包管理工具，它开创了包管理标准，其开发者还维护了世界上最多人使用的分布式开源 JavaScript 包管理网站 npmjs.com.</li>
<li><a href="https://yarnpkg.com/en/" rel="noopener noreferrer">Yarn</a>: 它重新实现了 NPM, 与之相比，Yarn 具有相同的管理方式，但是安装速度更快，稳定性更好，而且提供了一些新特性（例如 Yarn workspaces），用于大型开发。</li>
<li><a href="https://rushjs.io/zh-cn/pages/maintainer/package_managers/pnpm.js.org/" rel="noopener noreferrer">PNPM</a>: 它提供了一个全新的包管理模式，该模式解决了<a href="https://rushjs.io/zh-cn/pages/advanced/phantom_deps/" rel="noopener noreferrer">“幻影依赖”和“ NPM 分身”</a>的问题，同时<a href="https://en.wikipedia.org/wiki/Symbolic_link" rel="noopener noreferrer">符号链接</a>使之与 NodeJS 模块解析标准保持 100% 兼容。</li>
</ul>

<h2 id="三package-lockjson">三、package-lock.json</h2>
<p>不同包管理工具生成的锁定文件都不一样。</p>
<ul>
<li> 锁定包的版本，确保再次下载时不会因为包版本不同而产生问题</li>
<li>加快下载速度，因为该文件中已经记录了项目所依赖第三方包的树状结构和包的下载地址，重新安装时只需下载即可，不需要做额外的工作</li>
</ul>
<h2 id="四packagejson">四、package.json</h2>
<p>项目依赖和开发依赖</p>
<ul>
<li>项目依赖就是这个产品线上运营所依赖的模块，在文件的dependencies字段</li>
</ul>
<p>npm install 包名</p>
<ul>
<li>开发依赖就是项目的开发阶段需要依赖，线上运营阶段不需要依赖的第三方包，称为开发依赖，devDependencies字段    </li>
</ul>
<p>npm install 包名 --save-dev</p>
<ul>
<li>npm install --production，在本地下载依赖的包</li>
<li>里面的script使用：npm run XXX</li>
</ul>
