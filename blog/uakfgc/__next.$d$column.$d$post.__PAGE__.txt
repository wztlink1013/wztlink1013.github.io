<h2 id="c指针">C指针</h2>
<p>相关概念的理解容易混淆，记住之前学习理解的一个准则！<code>*p 的理解意义就是p 所指向的那个东西</code></p>
<ul>
<li>取地址符 <code>&#x26;</code> </li>
<li>解引用运算符 <code>*</code> </li>
</ul>
<blockquote>
<p>参考：</p>
<ul>
<li><a href="https://blog.csdn.net/soonfly/article/details/51131141" rel="noopener noreferrer">https://blog.csdn.net/soonfly/article/details/51131141</a></li>
</ul>
<p>* 有3个用途</p>
<p>1. 乘号（Multiply）： 2*3 就是6</p>
<p>2. 声明指针（Pointer Statement）： int a =5; int* ptr=&#x26;a;就是声明变量a是5，把a的地址附到指针ptr上</p>
<p>3. 解引用 （Dereference）： *ptr 单独拿出来就是找出 ptr指针指向的值，按照第二点的说法就是5.</p>
<p>&#x26;叫做取地址符号</p>
<p>• 一般指针只能接受一个内存地址而不能接受一个值</p>
<p>• int a =5; int* ptr=a;就是错误的，指针不能接受一个值</p>
<p>• int a =5; int* ptr=&#x26;a;才对，把a的地址给指针ptr</p>
<p>指针理解的话你可以这么想。</p>
<p>你问我书在哪。我说在书架第一层。</p>
<p>你问我书在哪。我说在那个桌子上的纸条上写着位置。这样的话那个纸条就是指针。</p>
<p>纸条上写着，书在书架第一层，这就是地址，他并不是书的实体</p>
<p>真正的书在书架第一层，顺着地址去找吧</p>
</blockquote>
<h2 id="c结构体">C结构体</h2>
<h3 id="一些概念">一些概念</h3>
<blockquote>
<ul>
<li>结构体:构造（定义新的数据类型）</li>
<li>结构体变量:定义（两种）；结构体变量访问结构体里面的成员：<code>.</code>；指针访问成员的时候<code>-></code></li>
<li>结构体数组：变量很多</li>
<li>结构体指针：指向结构体变量的指针，定义：<code>struct Student *p</code>；指向结构体数组的指针</li>
</ul>
</blockquote>
<ul>
<li>C里面的<strong>结构体、共用体、枚举体</strong>根据这几类来构造新的数据类型，比如链表的初始实现，就是利用指针和结构体来实现</li>
<li><strong>typedef</strong>给结构体制定新的类型名  eg：计数专用变量<code>typedef int Count</code></li>
</ul>

<h3 id="bitsstdch">✨bits/stdc++.h</h3>
<ul>
<li>
<p>万能头文件：几乎包含所有的可用到的C++库函数</p>
</li>
<li>
<p>缺点</p>
</li>
<li>
<p>编译时间慢，具有不可移植的问题，很多编译器和oj不支持，虽然现在noip支持了...</p>
</li>
<li>
<p>如果你用了bits/stdc++.h，那么你很大几率就会用using namespace std;而不是using std::cin; using std::cout;这样的。这会导致你的某些变量或函数已经被包含了而你不知道（关键字作为函数名）</p>
</li>
<li>
<p>还有很重要的一点，就是用bits很占内存，某些卡内存的题根本用不了</p>
</li>
<li>
<p>具体头文件内容</p>
</li>
</ul>

<p><strong>类的继承和派生</strong></p>
<p>一、派生类的定义：</p>
<p>父类class Base{}</p>
<p>派生子类：单一继承class Derived：public Base{}；</p>
<p>多重继承Class Derived：public Base1，pretect Base2{}；</p>
<p>继承的类型：</p>
<p>单一继承：只有一个基类</p>
<p>多重继承：有多个基类</p>
<p>继承方式：</p>
<p>private继承：所有的数据成员都为子类的的私有成员</p>
<p>public继承：父类的数据类型怎样，在子类类型不变</p>
<p>protect继承：所有的数据成员和成员函数都为字类的保护成员</p>
<p>ps：①父类的private数据成员和成员函数不能被子类所继承</p>
<p>②一般很少用protect和private两种继承，因为两种改变了之前基类的访问属性，限制了这些的进一步派生，所以很少使用</p>
<p>二、派生类的构造和析构</p>
<p>构造和析构的调用顺序：</p>
<p>①所有虚基类的构造函数</p>
<p>②基类的构造函数</p>
<p>③对象成员的构造函数</p>
<p>④自身派生类的构造函数</p>
<p>ps：析构函数的调用顺序则正好相反、</p>
<p>虚基类保证调用一次构造函数。两个子类都有同一个基类的虚基类继承，构造函数只调用一次</p>
<p>带参数的构造函数：</p>
<p>子类里面，构造函数的初始化要连带着基类的构造函数的初始化</p>
<p>eg：classA(int a,int b,int c):classB(a*2),classC(a,b){}</p>
<p>三、同名冲突和解决方案</p>
<p>解决①双冒号法：：</p>
<p>基类和子类当中有相同名字的数据成员和成员函数，</p>
<p>访问的时候：相同的名字：：数据成员/成员函数</p>
<p>解决②定义虚基类virtual</p>
<p>eg：class furniture{}；</p>
<p>Class sofa ：virtual public furniture{}；</p>
<p>Class bed：virtual public furniture{}；</p>
<p>Class sofabed：public sofa，public bed{}；</p>
