<p><strong>CSS Unicode字体</strong></p>
<ul>
<li>
<p>为什么使用 Unicode字体</p>
</li>
<li>
<p>在 CSS 中设置字体名称，直接写中文是可以的。但是在文件编码（GB2312、UTF-8 等）不匹配时会产生乱码的错误。</p>
</li>
<li>
<p>xp 系统不支持 类似微软雅黑的中文。</p>
</li>
<li>
<p>解决方案一： 你可以使用英文来替代。 比如<code>font-family:"Microsoft Yahei"</code>。</p>
</li>
<li>
<p>解决方案二： 在 CSS 直接使用 Unicode 编码来写字体名称可以避免这些错误。使用 Unicode 写中文字体名称，浏览器是可以正确的解析的，记住！是在CSS里面</p>
</li>
</ul>

<h3 id="line-height">line-height</h3>
<ul>
<li>行间距：line-height属性用于设置行间距，就是行与行之间的距离，即字符的垂直间距，一般称为行高。</li>
<li>单位：line-height常用的属性值单位有三种，分别为像素px，相对值em和百分比%，实际工作中使用最多的是像素px</li>
</ul>
<p>一般情况下，行距比字号大7.8像素左右就可以了。</p>
<p>line-height: 24px;</p>
<h3 id="text-indent">text-indent</h3>
<ul>
<li>作用：text-indent属性用于设置首行文本的缩进，</li>
<li>其属性值可为不同单位的数值、em字符宽度的倍数、或相对于浏览器窗口宽度的百分比%，允许使用负值,</li>
<li>建议使用em作为设置单位，<strong>1em 就是一个字的宽度 如果是汉字的段落， 1em 就是一个汉字的宽度</strong></li>
</ul>
