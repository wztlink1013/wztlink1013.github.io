4:T17af,<h2 id="对象多个属性至少一个属性存在">对象多个属性至少一个属性存在</h2>
<p>假如我有一个对象，对象里面有三个属性abc都是字符串类型，a属性必须存在，bc属性至少有一个必须存在，我如何用typescript来描述这个类型</p>
<p>你可以使用 TypeScript 的交叉类型和条件类型来描述这个对象类型。下面是一个示例：</p>
<div class="code-block"><pre><code class="hljs language-typescript"><span class="hljs-keyword">type</span> <span class="hljs-title class_">MyObject</span> = {
  <span class="hljs-attr">a</span>: <span class="hljs-built_in">string</span>;
} &#x26; (
  | { <span class="hljs-attr">b</span>: <span class="hljs-built_in">string</span>; <span class="hljs-attr">c</span>?: <span class="hljs-built_in">string</span> }
  | { <span class="hljs-attr">c</span>: <span class="hljs-built_in">string</span>; <span class="hljs-attr">b</span>?: <span class="hljs-built_in">string</span> }

</code></pre><button type="button" class="code-copy" data-copy-code="" aria-label="复制代码"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" aria-hidden="true"><rect x="8" y="8" width="12" height="12" rx="2"></rect><path d="M16 8V4a1 1 0 0 0-1-1H4a1 1 0 0 0-1 1v11a1 1 0 0 0 1 1h4"></path></svg><span>复制</span></button></div>
<p>在这个定义中，<code>a</code> 属性是必需的，而 <code>b</code> 和 <code>c</code> 至少有一个是必需的。</p>
<h2 id="数组必须有值">数组必须有值</h2>
<p>要在 TypeScript 中表示一个属性值为非空数组，你可以使用元组类型和泛型的结合来确保数组至少有一个元素。下面是一个示例：</p>
<div class="code-block"><pre><code class="hljs language-typescript"><span class="hljs-keyword">type</span> <span class="hljs-title class_">MyObject</span> = {
  <span class="hljs-attr">a</span>: <span class="hljs-built_in">string</span>;
  <span class="hljs-attr">b</span>: <span class="hljs-built_in">string</span>[];
};

<span class="hljs-comment">// 确保 b 是非空数组</span>
<span class="hljs-keyword">type</span> <span class="hljs-title class_">NonEmptyArray</span>&#x3C;T> = [T, ...T[]];

<span class="hljs-keyword">type</span> <span class="hljs-title class_">MyObjectWithNonEmptyArray</span> = {
  <span class="hljs-attr">a</span>: <span class="hljs-built_in">string</span>;
  <span class="hljs-attr">b</span>: <span class="hljs-title class_">NonEmptyArray</span>&#x3C;<span class="hljs-built_in">string</span>>;
};

<span class="hljs-comment">// 示例</span>
<span class="hljs-keyword">const</span> <span class="hljs-attr">example</span>: <span class="hljs-title class_">MyObjectWithNonEmptyArray</span> = {
  <span class="hljs-attr">a</span>: <span class="hljs-string">"Hello"</span>,
  <span class="hljs-attr">b</span>: [<span class="hljs-string">"World"</span>], <span class="hljs-comment">// b 数组至少有一个元素</span>
};
</code></pre><button type="button" class="code-copy" data-copy-code="" aria-label="复制代码"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" aria-hidden="true"><rect x="8" y="8" width="12" height="12" rx="2"></rect><path d="M16 8V4a1 1 0 0 0-1-1H4a1 1 0 0 0-1 1v11a1 1 0 0 0 1 1h4"></path></svg><span>复制</span></button></div>
<p>在这个示例中，<code>NonEmptyArray&#x3C;T></code> 是一个类型别名，用于表示至少包含一个元素的数组。<code>MyObjectWithNonEmptyArray</code> 这样定义后，<code>b</code> 必须是一个非空字符串数组。</p>
